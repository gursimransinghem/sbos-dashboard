# SBOS Dashboard

## What This Is
React + Recharts financial dashboard for Sim's SBOS (Snowball OS) tracking.
Debt avalanche progress, net worth, income vs expenses visualization.

## Project-Specific Rules
- React + Recharts only — no additional charting libraries
- Financial data is sensitive — no real account numbers in source code
- Use mock/dummy data in the codebase; real data loaded at runtime from config
- Keep charts responsive — dashboard is viewed on both desktop and mobile
