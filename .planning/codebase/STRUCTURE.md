## Directory Purposes

**src/:**
- Purpose: All React source code
- Contains: Components, styles, data, entry points
- Key files: `data.js` (centralized state), `App.jsx` (root), `index.css` (theme)

**src/components/:**
- Purpose: Feature components — each represents one financial domain
- Contains: 9 domain components + 1 layout wrapper
- Key files: `Section.jsx` (reusable wrapper), `DebtAvalanche.jsx` (largest, most complex)

**src/assets/:**
- Purpose: Static images (SVGs, PNGs)
- Contains: placeholder graphics, logo assets

**public/:**
- Purpose: Static files served without hashing (favicons, manifest)
- Contains: favicon.svg (app icon), icons.svg (reusable icon sprites)

**data/:**
- Purpose: External data sources
- Contains: CSV exports from Monarch Money (transaction history, spending breakdown)

**dist/:**
- Purpose: Built output (generated by Vite)
- Contains: minified JS/CSS, index.html, assets
- Committed: No (in .gitignore)

## Key File Locations

**Entry Points:**
- `index.html`: Browser entry — loads root div, imports main.jsx
- `src/main.jsx`: React entry — mounts App to DOM
- `src/App.jsx`: Root component — orchestrates dashboard layout

**Data:**
- `src/data.js`: Centralized financial data object — imports only, no mutations

**Configuration:**
- `vite.config.js`: Vite bundler config (React plugin, base path)
- `eslint.config.js`: ESLint rules (recommended + React hooks + React refresh)
- `package.json`: Dependencies, scripts

**Styling:**
- `src/index.css`: Global theme (colors, fonts, animations, recharts overrides)

**Components:**
- `src/components/Section.jsx`: Layout wrapper — collapsible card container
- `src/components/DebtAvalanche.jsx`: Debt management section (payoff scenarios, card status)
- `src/components/SpendingMonitor.jsx`: Budget vs. spending caps enforcement
- `src/components/BillsCalendar.jsx`: Fixed obligations timeline
- `src/components/BudgetBuilder.jsx`: Zero-based budget allocation (Ramsey method)
- `src/components/WealthDiagnostic.jsx`: Assets/liabilities breakdown
- `src/components/CashFlowAnalysis.jsx`: Income vs. expenses projection
- `src/components/SpendingTrends.jsx`: Monthly spending history analytics
- `src/components/NetWorth.jsx`: Asset/liability pie charts, net worth summary
- `src/components/TaxOptimizer.jsx`: 2025 tax filing status & deductions

## Naming Conventions

**Files:**
- Components: `PascalCase.jsx` (e.g., `DebtAvalanche.jsx`, `Section.jsx`)
- Styles: `index.css` (global), no component-scoped CSS
- Data: `data.js` (singular)
- Config: lowercase with dots (e.g., `vite.config.js`, `eslint.config.js`)

**Functions:**
- Format helpers: `fmt(n)` → currency display (camelCase, short names)
- Components: `PascalCase` for React components
- Local helpers: camelCase (e.g., `simulateAvalanche`, `getPayoffDate`)

**Variables:**
- Constants: UPPERCASE (e.g., `COLORS`, `statusColor`)
- Data objects: camelCase (e.g., `creditCards`, `totalCCDebt`, `billsSummary`)
- Component state: camelCase (e.g., `open`, `showScenarios`)

**CSS/Theme:**
- Colors: `--color-name` in lowercase (e.g., `--cyan`, `--red`, `--green`)
- Semantic variants: `--color-name-dim` (lower opacity), `--color-name-glow`
- Backgrounds: `--bg-deep`, `--bg-surface`, `--bg-elevated`, `--bg-hover`
- Text: `--text-primary`, `--text-secondary`, `--text-muted`
- Borders: `--border`, `--border-accent`

## Where to Add New Code

**New Feature Component:**
1. Create `src/components/NewFeature.jsx` (PascalCase)
2. Import data from `src/data.js` (add fields to data.js if needed)
3. Import `Section` from `src/components/Section.jsx`
4. Wrap content: `<Section number="X" label="LABEL" title="TITLE" gradient="..."><Content/></Section>`
5. Import & render in `src/App.jsx`, place in grid layout
6. Use CSS variables for styling (no scoped CSS files)

**New Data Field:**
1. Add to appropriate section in `src/data.js` (income, debts, spending, bills, subscriptions, assets, liabilities, etc.)
2. Add summary calculations if derived (e.g., `totalCCDebt = creditCards.reduce(...)`)
3. Export the field: `export const newField = ...`
4. Import in consuming component

**New Utility/Helper:**
1. **NOT recommended** — currently utilities are inline (fmt, fmtExact, simulateAvalanche)
2. If creating shared utility, place in `src/utils.js` (does not exist yet)
3. Import in components that use it

**Styling Changes:**
1. For global theme: Edit `src/index.css` (CSS variables at `:root`)
2. For component styling: Use inline `style={{}}` objects with `var(--*)`
3. No CSS modules, no Tailwind — pure CSS variables + inline styles
